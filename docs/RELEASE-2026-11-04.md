# Watch update · 4 November 2026

This source update brings Apple TV build 30 and the host improvements into the repository alongside Samsung 0.335, already committed in 09edd06.

## Included

Apple TV gains native BBC UHD/HLG with an on-device, loopback-only DASH-to-HLS bridge, existing privately provisioned client access, and verified decoded-dimension badges. It includes the current public BBC HD route, actual source/version timing, shared transport controls, chapters, verified intro/recap skips, Up next and optional cancellable autoplay. UI updates include viewport-sized cards, flowing provider/title layouts, cleaner Settings, Favourites and UHD filters, wider BBC UHD discovery, and explicit first-row/filter focus movement.

The host adds playback-feature normalization and APIs, cancellable series queues, timestamp-preserving BBC version handover, six-hour BBC UHD discovery/cache, and ITV runtime/film metadata corrections. Discovery does not prepare upcoming playback or replace active sessions. Samsung's already committed update provides the same chapter/skip/queue contract through its own authenticated gateway and remote controls.

## Validation

- Apple TV build 30 compiled and installed on physical Apple TV.
- Blue Planet III: Open Ocean was confirmed on that device at 3840×2160 with HLG-signalling source metadata; the user confirmed the UHD badge, picture and sound. A fresh playback snapshot reported about 30 seconds buffered and zero stalls/retries. This is a short playback check, not a full-programme reliability claim.
- Wider catalogue verification projected 86 programmes/specials and three films with currently available BBC UHD editions. This is metadata verification, not individual playback verification for every title.
- Publication snapshot: all 135 Watch gateway Python tests, five BBC login-adapter tests, and four Samsung playback-adapter tests passed.
- Native provider, UHD/DASH/fragment-normalization and playback-extras Swift suites passed.
- Samsung widget extras and JavaScript syntax checks were run before publication; see component documentation for pending physical remote checks.
- Staged source was checked for private keys, account tokens, literal bearer credentials, personal email addresses and signed media URLs; none were detected. Existing service state, account details, provisioning packages, signing files and per-machine tools are excluded.

## Remaining physical checks

Longer UHD viewing, manual UHD scrubbing and the short-row Siri Remote filter-navigation fix still need further device observation. Samsung chapter/verified-skip and end-to-next transitions retain their documented physical-verification limits. No upcoming stream is prepared while the current episode plays.

## Deployment

The running Apple TV and Pi installation were updated during development. Publishing this repository does not restart services or change ongoing playback. UHD access material remains in Apple TV device-only Keychain storage and is not part of this source publication. Other installations must supply their own configuration and sign their own app builds.
